## FireRed QoL + Hard

`firered-qol-hard/` is a Pokémon FireRed romhack with quality-of-life
improvements and a tougher difficulty curve, distributed as a `.bps` patch.
See its [README](firered-qol-hard/README.md).

## HeartGold QoL + Hard

`heartgold-qol-hard/` is the same recipe for Pokémon HeartGold, built on
hg-engine, distributed as an `.xdelta` patch. v0.1 is a playtest build. See
its [README](heartgold-qol-hard/README.md).

## FireRed Playtester

`firered-ai/` is an unattended playtester for the QoL + Hard hack (and
vanilla FireRed). It plays the patched ROM in several emulators at once, hunts
for crashes, softlocks, corrupt data and broken challenge rules, and writes a
report with a save state and video for each problem. It also includes an
optional reinforcement-learning agent. See its [README](firered-ai/README.md).
