# #352 Kecleon

*The Color Swap Pokémon* — **Normal**

> It changes body color to blend in with its surroundings. It also changes color if it is happy or sad.

Height 1 m (3′03″) · Weight 22 kg (48.5 lbs)

## Abilities

- **Color Change**: Changes type to foe's move.

## Where to find it

- **Route 16**: Grass / cave Lv 22 (5%)
- **Safari Zone West**: Grass / cave Lv 25 (10%)
- Breeding: hatches from an Egg left by a Kecleon at the Four Island Day Care
